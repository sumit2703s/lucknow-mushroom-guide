# 🍄 Lucknow Mushroom Guide — Cafes, Restaurants & Luxury Hotels

A high-performance, interactive intelligence platform mapping where mushrooms are used at scale across Lucknow. Designed for both culinary enthusiasts (Foodies) and mushroom growers/vendors (B2B suppliers).

---

## 🌟 Key Features

### 1. 🍽️ 87+ Verified Lucknow Venues
- Covers every major zone: **Hazratganj, Gomti Nagar, Chowk, Aliganj, Indira Nagar, Shaheed Path, Phoenix Palassio, Lulu Mall, Kapoorthala, Aminabad, Charbagh, Jankipuram, and more**.
- Verified data points sourced from **Google Maps, Zomato, and Swiggy** with color-coded verification badges.

### 2. 🍄 Multi-Select Mushroom Variety Filter
- Filter venues dynamically by mushroom varieties:
  - ⚪ Button Mushroom
  - 🦪 Oyster Mushroom
  - 🌰 Shiitake Mushroom
  - 🤎 Portobello Mushroom
  - 🍄 Cremini Mushroom
  - ✨ Morel (Gucchi)
  - 👑 King Oyster
  - 🥢 Enoki
  - 🌾 Dhingri
  - 💎 Truffle Oil
- Real-time venue match counts, interactive active filter strip, and one-click mushroom tag filtering.

### 3. 🔍 Full Venue Detail Modal (Popup)
- Click on any venue card or "📍 Full Details" button to open an interactive modal.
- Includes:
  - **Quick Action Bar**: Direct call button (`tel:`), One-click Google Maps search, B2B calculator selection, and info copy.
  - **Mushroom Specialization Profile**: Varieties used, full signature dishes menu with prices (₹).
  - **Foodie Insider Secret**: Curated recommendations and culinary tips.
  - **B2B Procurement Intel**: Weekly demand intake (kg), monthly procurement turnover, packaging requirements, and delivery schedule.

### 4. 🛰️ AI Radar "Scan Lucknow" Simulation
- Concentric circle scanning HUD with live radar sweep and animated blip detections.
- Telemetry progress bar streaming across 16 Lucknow localities.
- Dynamic venue discovery that sorts newly scanned spots to the top with `🔥 NEW` badges.

### 5. 💼 Dual Modes & B2B Calculator
- **Foodie Mode**: Focuses on signature dishes, pricing, atmosphere, and culinary highlights.
- **B2B Mode**: Displays weekly kg consumption, packaging needs, supplier contact numbers, and an interactive revenue calculator with customizable price/kg and CSV export.

## 🚀 Getting Started

### Local Setup
No build tools or heavy dependencies required. Built with Vanilla HTML5, CSS3, and JavaScript.

```bash
# Clone the repository
git clone https://github.com/sumit2703s/lucknow-mushroom-guide.git

# Navigate into the project folder
cd lucknow-mushroom-guide

# Start any local HTTP server (e.g. Python)
python3 -m http.server 8080
```

Open your browser at `http://localhost:8080/`.
